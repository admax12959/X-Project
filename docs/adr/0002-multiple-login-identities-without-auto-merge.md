# 一个用户挂多个登录身份，禁止按邮箱自动合并

> 2026-10-14 更新：本地身份已改名为邮箱身份，用登录邮箱加密码登录，不再用用户名登录（见 `docs/design/iam-scope.md`）。下文中的“本地账号”“本地用户”分别指邮箱身份、只有邮箱身份的用户。

一个用户可以同时拥有 LDAP 身份和本地账号密码身份，两者共享同一份用户信息。追加身份只有两种方式：用户在已登录状态下主动绑定（必须用新身份完成一次认证），或由管理员绑定。我们否决了"LDAP 登录时按邮箱或用户名自动合并到已有本地用户"的方案，因为邮箱相同不能证明是同一个人，自动合并会带来账号被接管的风险。

## Consequences

- 绑定了 LDAP 的用户，显示名、邮箱、部门以 LDAP 为准，每次登录时同步。
- LDAP 侧删除或禁用账号时，只让对应的 LDAP 身份失效，用户本身和他的其他身份不受影响。

# 二次验证只用验证器和恢复码，不用邮件验证码，不做"记住此设备"

二次验证的方式只有验证器（TOTP）和恢复码。我们否决了邮件验证码作为二次验证方式：NIST SP 800-63B 第 4 版禁止用邮件做带外认证；而且邮箱身份本身就用邮箱登录，邮件验证码等于让同一个邮箱同时充当两个因素。我们也否决了"记住此设备，一段时间内免二次验证"，因为 NIST 不允许用设备记忆替代认证，被盗的会话 Cookie 会连带绕过二次验证。

## Consequences

- 验证器丢失只能靠恢复码，或由管理员重置（通知本人并记入审计）；另有容器内命令行作为唯一管理员被锁时的应急入口。
- 邮件验证码只用于验证邮箱和找回密码。
- 数据模型为以后的通行密钥（Passkey/WebAuthn）预留位置。

# 头像存私有存储桶，经后端鉴权后返回

头像上传和下载都经过后端：上传时后端校验格式、去除元数据、裁剪重编码后写入存储；下载时浏览器请求后端接口，后端校验登录状态后读出对象返回，并设置长期缓存。存储桶保持私有并开启"阻止公共访问"，没有任何公网地址可被盗刷。我们否决了公共读桶加 Referer 白名单，因为 Referer 可以随意伪造，空 Referer 也无法正确处理；否决了浏览器直传加签名 URL，因为头像本来就要在后端处理，直传还要求每种存储配置 CORS，本地磁盘也不支持预签名。

## Consequences

- 头像流量全部经过后端，头像小且有浏览器缓存，内网规模下可以接受。
- 一套 S3 兼容实现覆盖阿里云 OSS、腾讯云 COS、MinIO，另有本地磁盘实现。
- 上传接口按用户限流，每个用户只保留一个当前头像对象，定时清理孤儿对象。

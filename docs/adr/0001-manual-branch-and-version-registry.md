# 分支和版本人工登记，仓库关联只保存平台和项目 ID

第一期中，维护线和版本由 Owner 在工具里人工登记，不从 GitLab/GitHub 同步，因为分叉原因、谱系和生命周期这些信息 Git 本身表达不了。仓库关联在建立时调用一次平台 API 校验，并保存代码平台和平台侧不会变的项目 ID（不只保存路径），这样仓库改名或迁移 group 后关联依然有效，以后操作仓库（建分支、打 tag、识别 cherry-pick）时可以直接复用。

## Consequences

- 每个代码平台需要由管理员配置一个只读服务账号令牌。
- 人工登记的 tag 或 commit 目前不做校验，以后接入仓库操作时再补校验。

# LDAP、邮件服务、对象存储改为在管理后台配置，密钥加密存库

第二期起，LDAP、SMTP 和对象存储的参数都由管理员在管理后台配置并保存到数据库，取代第一期"LDAP 参数放在配置文件或环境变量中"的约定。这些配置需要在不重启、不改部署的情况下调整和验证（测试连接、发送测试邮件），而配置文件做不到。密码、令牌、访问密钥用 AES-256-GCM 加密后入库，主密钥只放在环境变量或 Docker secret 中，并记录密钥版本以便轮换。我们否决了"全部继续放配置文件"的方案，因为每次改 SMTP 或存储都要重新部署；也否决了"密钥明文存库"，因为数据库备份一旦泄露就等于泄露所有外部系统凭据。

## Consequences

- 配置文件只保留启动必需的内容：数据库连接、主密钥、初始管理员。
- 密钥字段在接口中只写不读，界面上只显示"已设置"。
- 主密钥丢失后，已存的密钥全部无法解密，需要管理员重新填写。
- 配置变更记入审计。
